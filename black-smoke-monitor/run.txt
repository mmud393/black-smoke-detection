HOW TO RUN BLACK SMOKE MONITOR
==============================

1. REQUIREMENTS
   - Python 3.11 or newer (python3 --version)
   - Internet, once, to install packages and download the model (~20 MB)
   - A camera RTSP URL that actually plays (test it in VLC first:
     Media > Open Network Stream)

2. EDIT .env  (in this folder)
   Required:
     RTSP_URL="rtsp://USER:PASS@CAMERA_IP:554/cam/realmonitor?channel=1&subtype=1"
        - Dahua format shown. Special characters in USER/PASS must be URL-encoded.
        - A Wowza "entrypoint" ingest URL gives 403 Forbidden; use a playback URL.
   For email alerts (leave EMAIL_ENABLED=false while testing; screenshots are
   still saved to ./screenshots, nothing is sent):
     EMAIL_ENABLED=true
     SMTP_HOST=smtp.gmail.com
     SMTP_PORT=587
     SMTP_USERNAME="you@gmail.com"
     SMTP_PASSWORD="<Gmail app password, not your normal password>"
     SMTP_FROM="you@gmail.com"
     SMTP_TO="receiver@example.com"        (comma-separate several)

3. RUN (one command)
     cd /Users/mac/Desktop/BSD/black-smoke-monitor
     ./run.sh

   First run creates .venv, installs packages, downloads the model into
   ./models, then starts monitoring. Stop with Ctrl+C.

4. RUN TESTS (no camera/email needed)
     .venv/bin/python -m pytest -q tests

5. WHAT YOU SHOULD SEE
   "Starting: camera=... email_enabled=..."
   "Camera ... connected"            -> stream works
   "Camera ... disconnected: ..."    -> stream cannot be opened (check RTSP_URL;
                                        it retries every CAMERA_RECONNECT_SECONDS)
   "Black smoke confirmed; screenshot ..." -> event detected, JPEG saved

6. TUNING (in .env, test on real footage of your camera)
   MODEL_CONFIDENCE_MIN           lower = more smoke candidates
   BLACK_LUMA_MAX                 higher = lighter smoke counts as "black"
   BLACK_DARK_PIXEL_RATIO_MIN     lower = easier to pass the dark check
   MOTION_PIXEL_RATIO_MIN         lower = less motion required
   CONFIRMATION_POSITIVE_FRAMES / CONFIRMATION_WINDOW_FRAMES
   EMAIL_COOLDOWN_SECONDS         minimum gap between alert emails

7. NOTES
   - Not a certified fire alarm; do not rely on it as sole protection.
   - Model: pyronear/yolo11s_sensitive-detector. Its model card says Apache-2.0
     but the ONNX file metadata says AGPL-3.0: check licensing before company use.
   - Old implementation is kept in ./legacy for reference.
