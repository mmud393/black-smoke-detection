.ENV EXPLAINED (simple)
======================
The .env file holds all settings. Only RTSP_URL is required to start;
the rest have working defaults.


CAMERA
------
RTSP_URL                         The camera's video address. REQUIRED.
                                 Dahua example: rtsp://USER:PASS@CAMERA_IP:554/cam/realmonitor?channel=1&subtype=1
                                 Check it plays in VLC first.
CAMERA_NAME                      A name for the camera. Shown in logs and the email subject.
RTSP_TRANSPORT                   tcp (safe default) or udp. Change to udp only if tcp won't connect.
CAMERA_OPEN_TIMEOUT_MS           How long to wait when connecting (milliseconds).
CAMERA_READ_TIMEOUT_MS           How long to wait for each picture (milliseconds).
CAMERA_RECONNECT_SECONDS         Seconds to wait before trying again after the stream drops.
CAMERA_NO_FRAME_TIMEOUT_SECONDS  If no picture arrives for this long, the camera is treated as down.
                                 (No detection and no alert while it is down.)


SPEED
-----
PROCESS_FPS                      How many pictures per second are checked for smoke.
                                 Lower = less CPU. 2 is fine.
FRAME_MAX_WIDTH                  Big pictures are shrunk to this width before checking.
                                 The saved screenshot stays full size.


SMOKE MODEL (runs on your computer, no cloud)
---------------------------------------------
MODEL_REPO_ID                    Where the model is downloaded from (first run only).
MODEL_FILENAME                   Which file to download from there.
MODEL_PATH                       Where the model is saved on your computer.
                                 If the file is already there, nothing is downloaded.
MODEL_SMOKE_CLASS_NAME           The model's name for smoke. Leave as "item".
MODEL_CONFIDENCE_MIN             How sure the model must be (0 to 1).
                                 Lower = finds more smoke but more false alarms.


"IS IT BLACK SMOKE?" CHECK  (tune these using your own camera footage)
---------------------------------------------------------------------
BLACK_LUMA_MAX                   A pixel counts as dark if brightness is at or below this
                                 (0 = black, 255 = white). Raise it to accept greyer smoke.
BLACK_DARK_PIXEL_RATIO_MIN       How much of the moving smoke must be dark (0.50 = half).
                                 Lower = easier to trigger.
SMOKE_REGION_MIN_AREA_PX         Ignore smoke boxes smaller than this (in pixels).
MOTION_PIXEL_DIFFERENCE_MIN      How much a pixel must change between pictures to count as moving.
MOTION_PIXEL_RATIO_MIN           How much of the box must be moving. This stops still dark
                                 things (shadows, machines) from being called smoke.


WHEN TO SEND AN ALERT
---------------------
CONFIRMATION_WINDOW_FRAMES       Look at the last 5 checked pictures...
CONFIRMATION_POSITIVE_FRAMES     ...and alert only if at least 3 of them show black smoke.
                                 (This number can't be bigger than the window.)
EVENT_CLEAR_SECONDS              Smoke is "gone" after this many seconds with no detection.
                                 After that, a new smoke event can alert again.
EMAIL_COOLDOWN_SECONDS           Minimum wait between two alert emails (300 = 5 minutes).


SCREENSHOTS (one per alert)
---------------------------
SCREENSHOT_DIR                   Folder where alert pictures are saved (smoke boxed in red).
SCREENSHOT_JPEG_QUALITY          Picture quality, 1 to 100.


EMAIL
-----
EMAIL_ENABLED                    false = never sends email (screenshots are still saved).
                                 Change to true after the settings below are filled in.
SMTP_HOST                        Mail server. Gmail: smtp.gmail.com
SMTP_PORT                        587 for Gmail. (Port 465 is not supported.)
SMTP_USERNAME                    Your email address (the sender).
SMTP_PASSWORD                    Gmail "app password" - NOT your normal password.
                                 Create it in Google Account > Security (needs 2-Step Verification).
                                 Never share this.
SMTP_FROM                        The "From" address on the alert (usually same as username).
SMTP_TO                          Who receives alerts. Several addresses: separate with commas.
SMTP_TIMEOUT_SECONDS             How long to wait for the mail server on each try.
SMTP_RETRIES                     Extra tries if sending fails (2 = up to 3 tries).
EMAIL_SUBJECT_PREFIX             Start of the email subject line.


OTHER
-----
APP_TIMEZONE                     Timezone for times in emails and file names, e.g. Asia/Karachi.
LOG_LEVEL                        How much detail in logs: INFO (normal) or DEBUG (more).
